Installation pas à pas

  1. Télécharger l’APK

    Touche Télécharger l’APK ci-dessus depuis ton téléphone.

  2. Installer

    Ouvre le fichier téléchargé. Si Android le demande, autorise l’installation depuis ton navigateur, puis reviens et touche Installer.

  3. Ouvrir une première fois

    Lance MOLA4FR sur le téléphone pour terminer la configuration.

  4. Activer les sources inconnues dans Android Auto

    Ouvre les paramètres d’Android Auto, touche Version une dizaine de fois, puis dans ⋮ → Paramètres pour les développeurs, coche Sources inconnues.

  5. Brancher le téléphone à la voiture

    MOLA4FR apparaît dans le lanceur d’applications d’Android Auto.

Bon à savoir

La radio et les podcasts fonctionnent en général avec cette méthode. La vidéo, YouTube et la recopie d’écran peuvent rester masquées selon le téléphone et la version d’Android Auto.

Vidéo, YouTube, navigateur et recopie d’écran : uniquement à l’arrêt.

Questions fréquentes

Comment recevoir les nouvelles versions ?

Dans MOLA4FR : Paramètres → Interface → Mises à jour de l’application. La recherche se fait seulement quand l’application est ouverte, et l’installation demande ta confirmation.

J’ai déjà Mola, est-ce compatible ?

Oui. MOLA4FR a son propre identifiant : elle s’installe à côté de Mola sans la remplacer.

Comment changer la langue ?

Paramètres → Interface → Langue.
