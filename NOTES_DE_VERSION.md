# MOLA4FR 1.0.0 — première version

- **Interface entièrement en français** par défaut. La langue reste modifiable dans **Paramètres → Interface → Langue**.
- **Nouveau nom : MOLA4FR**, avec son propre identifiant d'application (`fr.mola4fr`). MOLA4FR peut donc être installée à côté de Mola, sans conflit.
- **Accueil vocal en français** : « Bonjour, bienvenue dans MOLA4FR. Bonne route ! » (désactivé par défaut).
- **Mises à jour** proposées depuis ce dépôt (`yuksel3803/Mola4fr`), uniquement quand l'application est ouverte.

Fonctions reprises de Mola 2.2.2 : TV/IPTV (listes M3U), radio, podcasts, YouTube, navigateur, recopie d'écran et touches au volant.

**Note :** première version signée avec une nouvelle clé. Aucune mise à jour depuis Mola n'est possible : installe MOLA4FR comme une nouvelle application.
